# TFT ST7789P3 (2.0", 3.3 В)

Модуль на задней стороне разводки (слева направо): **BL, CS, DC, RST, SDA, SCL, VCC, GND**. Интерфейс — **4-проводный SPI** (плюс управление подсветкой и сбросом).

## Таблица проводов

| Вывод TFT | Назначение        | Arduino Nano V3 | Примечание |
|-----------|-------------------|-----------------|------------|
| **GND**   | Общий минус       | **GND**         | Любой контакт GND на плате |
| **VCC**   | Питание 3.3 В     | **3V3**         | Только 3.3 В; **не** подключать к 5 V (VCC на Nano) |
| **SCL**   | SPI Clock         | **D13**         | Аппаратный **SCK** |
| **SDA**   | SPI Data (MOSI)   | **D11**         | Аппаратный **MOSI** |
| **CS**    | Chip Select       | **D10**         |  |
| **DC**    | Data / Command    | **D9**          |  |
| **RST**   | Сброс дисплея     | **D8**          | (можно на «не RST» пине Nano, это не системный сброс MCU) |
| **BL**    | Подсветка         | **D6**          | диммирование — ШИМ-пин, например **D6** (PWM) |

**Подсветка (если «белый экран» или мерцание):**

- Сначала попробуйте в прошивке **`kBacklightUsePwm = false`** и **`kBacklightActiveHigh = true`** — на BL часто дают **постоянный HIGH**, ШИМ с Nano (~490 Гц) иногда даёт артефакты или не тот режим для ключевого транзистора на плате модуля.
- Если картинка тёмная, а «белое» только равномерная засветка — проверьте **SPI (MOSI/SCK/CS/DC)**, **RST**, **3V3 и землю**; белое поле часто бывает при отсутствии обмена или неверной инициализации, а не только из‑за BL.
- Редко встречается **активный низкий** вход BL — тогда в `Config.h` выставьте **`kBacklightActiveHigh = false`**.

Пример логики для библиотек: `CS=D10`, `DC=D9`, `RST=D8`; при других пинах задайте их в инициализации драйвера.

## Важно по питанию

- На многих Nano вывод **3V3** выдаёт **ограниченный ток** (в документации часто указывают порядка десятков миллиампер — уточняйте по вашей ревизии). Дисплей с подсветкой может потреблять **больше**, чем даёт встроенный стабилизатор Nano с USB.
- Если подсветка тусклая, мерцает или Nano перезагружается — используйте **отдельный стабилизатор 3.3 В** (или модуль с AMS1117-3.3 и общей землёй с Nano) для **VCC** и при необходимости для **BL**.
- Логические уровни: при питании TFT от **3.3 В** выходы **D8–D13** атмеги при 5 В логике для многих модулей ST7789 на плате с регистрами допустимы, но **надежнее** либо питать MCU от 3.3 В, либо использовать **логические преобразователи уровня** на линиях SPI/DC/CS/RST, если даташит модуля требует строго 3.3 В на входах.

## Краткая шпаргалка SPI на Nano

- **SCK** → D13  
- **MOSI** → D11  
- **MISO** → D12 (для этого дисплея обычно не нужен)  
- **SS** → D10 (часто используют как CS дисплея)

После подключения в коде включите аппаратный SPI и задайте те же номера пинов, что и на проводах.

## Кнопка без фиксации → **D2**

| Контакт кнопки | Nano |
|----------------|------|
| Один вывод     | **D2** |
| Другой вывод   | **GND** |

В коде удобно включить **внутреннюю подтяжку к VCC**: `pinMode(2, INPUT_PULLUP)`. Тогда в покое на пине логическая «1», при нажатии замыкание на землю даёт **LOW**. На **D2** также доступно внешнее прерывание **INT0** (`attachInterrupt(digitalPinToInterrupt(2), ...)`) для реакции по фронту без постоянного опроса.

Если кнопка дребезжит — программный антидребезг или RC-фильтр на плате.

## Двухпиновый двухцветный (красный / синий) светодиод → **D4**, **D5**

Корпус на **два вывода**: внутри обычно два кристалла **встречно-параллельно** (одна полярность даёт красный, обратная — синий). Питается он **не от «GND + один пин»**, а **между двумя выводами портов**.

### Разводка

| Вывод LED | Подключение |
|-----------|-------------|
| Вывод **1** | **D4** (или через последовательный резистор — см. ниже) |
| Вывод **2** | **D5** |

Либо **один общий резистор** стоит **последовательно** в разрыве: **D4 — [R] — вывод 1 — вывод 2 — D5** (или резистор с другой стороны: **D4 — вывод 1 — вывод 2 — [R] — D5** — для ограничения тока без разницы).

### Логика в коде

| **D4** | **D5** | Результат |
|--------|--------|-----------|
| `HIGH` | `LOW`  | Зажигается **один** цвет (ток идёт в одну сторону через корпус) |
| `LOW`  | `HIGH` | Зажигается **другой** цвет |
| Одинаково (`HIGH`/`HIGH` или `LOW`/`LOW`) | | Оба цвета **выключены** (на диоде нет нужной разности потенциалов) |

Перед переключением полярности лучше кратко вывести оба пина в одинаковое состояние или перевести в **INPUT**, если хотите исключить кратковременные протечки — на практике часто достаточно стабильной пары уровней.

## Фототранзистор → **A1**

**Ваша сборка:** подтяжка коллектора резистором **10 кΩ** на **5 V**.

Схема для **npn**-фототранзистора с общим эмиттером:

| Вывод     | Подключение |
|-----------|-------------|
| Эмиттер   | **GND** |
| Коллектор | узел **A1**; от узла резистор **10 кΩ** на **5 V** |

При освещении ток через транзистор растёт — напряжение на **A1** **падает** (темно → выше по шкале ADC, светло → ниже). Опрос: `analogRead(A1)` или порог после калибровки.

Если понадобится сильнее «тянуть» вход к GND при свете — иногда уменьшают номинал подтяжки; **10 кΩ** — типичный компромисс. Общая земля с Nano обязательна.

## Сводка занятых пинов Nano

| Пин   | Назначение |
|-------|------------|
| **D2**  | Кнопка (к GND, `INPUT_PULLUP`) |
| **D4**  | Двухпиновый биколор: один вывод LED |
| **D5**  | Двухпиновый биколор: второй вывод LED (полярность D4/D5 HIGH–LOW выбирает цвет; **PWM**) |
| **D6**  | Подсветка TFT (PWM) |
| **D8**  | TFT RST |
| **D9**  | TFT DC |
| **D10** | TFT CS |
| **D11** | TFT SDA / MOSI |
| **D13** | TFT SCL / SCK |
| **A1**  | Фототранзистор, подтяжка **10 кΩ** → **5 V** |

Свободны, среди прочего: **D3**, **D7**, **D12** (MISO), **A0**, **A2–A7**, **I2C A4/A5** — при необходимости можно переназначить часть линий под новые датчики.
