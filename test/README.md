## Стимул на мониторе (`phototransistor_screen_test.py`)

Python-утилита в корне проекта: полноэкранный красный/синий стимул на мониторе для проверки фотоприёмника на экране. Тайминги и сценарии совпадают с прошивкой Arduino (`include/Config.h`, `SerialInput.cpp`).

### Установка

```bash
python -m pip install -r requirements-screen-test.txt
```

Нужны **Python 3** и **tkinter** (в стандартной сборке Python для Windows обычно уже есть). Для связи с Nano — **pyserial**.

### Запуск

```bash
python phototransistor_screen_test.py
```

Опции:

- `--port COM7` или `--port /dev/ttyACM0` — предвыбор порта (Windows / Linux).
- `--windowed` — без полноэкранного режима.

### Управление

Те же команды, что в Serial Monitor прошивки (115200):

| Клавиша | Serial | Действие |
|---------|--------|----------|
| **m** | `m` | Меню, отмена, экран выкл. |
| **c** | `c` | Калибровка: 5 с красный + 5 с синий |
| **r** | `r` | Прогрев 2,5+2,5 с, затем замер R↔B |
| **h** / **?** | `h` | Подсказка |
| **Esc** | — | Выход |

При выбранном COM-порте в шапке окна символ уходит на устройство и **параллельно** запускается локальный стимул.

В блоке **Serial** в окне дублируются строки прошивки (`[CAL]`, `[CAL_RESULT]`, `[ABORT]`, `[LAT]`, `[RESULT]` и т.д.). Если устройство сообщает **`status=FAIL`** (например `dRB low`) или **`[ABORT]`**, локальный стимул **останавливается** — замер на экране не продолжается, как на Arduino.

### Порты (Windows / Ubuntu)

Список портов обновляется кнопкой **«Обновить»**. Пункт **«(нет — только экран)»** — работа без Arduino.

На Linux при ошибке доступа: `sudo usermod -aG dialout $USER` и перелогин.

### Задержка экрана

Ползунок **«Задержка (только замер)»**: шаг **5 мс**, диапазон ±500 мс. Сдвигает только смену цвета **в фазе замера** (эмуляция запаздывания картинки относительно LED). Прогрев и калибровка с Arduino идут **без сдвига**.

### Тайминги (по умолчанию в `Config.h`)

| Режим | Длительность |
|-------|----------------|
| Калибровка | 2× 5000 мс (R, B) |
| Прогрев | 2× 500 мс (R, B) |
| Замер | полупериод 750 мс, сессия 22,5 с |

При изменении `kLatencyMaxExpectedMs` в прошивке те же константы нужно обновить в начале `phototransistor_screen_test.py`.
